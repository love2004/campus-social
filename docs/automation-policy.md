# 自動選稿、產稿與圖卡規則檢查單

2026-11-06。對應目前測試站，可在「單位設定 → 自動化規則」先預覽，再儲存。

## 三種時間

| 工作 | 目前設定 | 可調整方式 |
| --- | --- | --- |
| 來源擷取 | 啟用的來源每 120 分鐘整理一次，亦可按「立即整理」 | 調整來源擷取間隔。預覽顯示上次及下次預計時間 |
| 自動產稿 | 來源整理完成後挑選候選資料，背景工作依序執行 | 可切換成指定星期及每日時段。表單提供週一至週五 08:30、15:00 作為可檢查的起始設定，切換與儲存後生效 |
| 對外發佈 | 每週一 10:00，台北時間 | 在「週期與日曆」調整。只有已核准、仍有效且平台 API 設定齊全的稿件可送出 |

08:30 與 15:00 是方便承辦人分批審稿的起始建議。各平台的實際發佈時段應依單位受眾及成效調整。四平台編輯研究另見 [文案與圖卡設定](platform-content-rules.md)。

## 實際選稿順序

1. 使用 Codex Web Search 讀取公開來源，保存摘要、短引文、網址及圖片候選。同網址去重，對新擷取的相同原文記錄重複來源。
2. 排除已封存、超出時效、命中排除詞、未符合關注主題／包含詞，以及少於 200 字的原文。主題與包含詞皆留白時，候選範圍涵蓋全部來源主題。
3. 從尚無產稿紀錄的可用素材中，優先挑選和近期已排入稿件不同來源、不同分類且標題關鍵詞重疊較少的文章。條件相近時優先較新的素材。預設每天最多排入 2 篇、每週最多 5 篇。AI 略過與失敗也計入自動嘗試上限，手動要求產稿另行處理。
4. 啟用「AI 語意選稿」後，先要求 AI 判斷相關性、原文是否足夠、是否為單篇文章及活動期限。預設至少 70 分、3 個互不重複的可核對事實，且期限尚未到。
5. 判斷保存 `eligible`、`score`、`category`、`reason`、`facts`、`expiresAt` 與時間。未達門檻的資料會保留略過原因。通過者才交由 AI 產生四版待審稿。

AI 語意選稿目前預設關閉，確認讀者、關注主題與規則後可自行啟用。AI 判斷會額外使用目前選用的文字服務。「先檢查規則與候選素材」只做固定條件預覽，顯示剩餘篇數與候選原因。

## 寫稿規則

正文預設每平台 200～300 字，含標點，排除空白、網址及獨立 hashtag。四版使用同一來源事實，包含背景、重點與具體總結。篇幅不合規時用同一服務修訂一次，仍未符合則回報失敗。

| 平台 | 產稿表達方式 |
| --- | --- |
| Facebook | 以讀者熟悉的場景或具體問題切入，整理 2～3 個重點，附主來源與實際採用的公開參考連結 |
| Instagram | 有資訊的首句、短段落與重點、總結及 0～3 個相關標籤 |
| Threads | 單一觀察、具體事實、一句總結或適合的問題，至多一個來源連結。送出全文另檢查 500 字元限制 |
| LINE | 消息標題、可核對的日期／對象／地點、單一行動及來源連結，預設不加 hashtag |

日期、人物、成果數字與連結需有來源。區分報導日期和事件日期，已結束活動以事實回顧。文案、圖片及期限經人工核對並核准後，才可發佈。

自動排入的公開文章會依主題產生搜尋詞並閱讀公開全文。採用近期事件或網路文化時，獨立審稿會核對相關性、日期及逐字引文。查不到合適資料或引用未通過審查時，草稿會以原始素材成文。打開待審草稿可查看搜尋詞、實際採用的參考網址與核對紀錄。

網路梗優先查台灣來源與社群聲量資料。採用時須有近 90 天台灣流傳的正文證據，審稿會核對梗的用法、流傳證據以及貼文中的實際段落。封面先交代主題，正文用白話帶出笑點。查不到相關且有證據的梗時，使用已查證的時事或原始素材。

## 作圖規則

| 模式 | 行為與啟用方式 |
| --- | --- |
| 人工選圖製卡 | 目前模式。AI 提供主題配圖描述與圖卡摘要，承辦人選圖並排版 |
| 自動品牌套版 | 以品牌色底圖加短標題與摘要建立圖卡，保存可編輯配方。來源照片留給承辦人另行挑選 |
| 素材照片套版 | 用第一張可用的素材照片作底圖，沒有照片時使用品牌色 |
| 自動 AI 圖卡 | 管理者明確選用並啟用生圖後，生成主題無字概念底圖，再疊加可編輯文字。2026-11-07 新增 Codex 訂閱生圖服務；選用 Images API 時才需要 API 金鑰、另外計費並套用本機預算保留 |

一般素材可設定每篇 1、3、4 或 5 張圖卡。多張圖卡共用底圖，第一張為封面，後續圖卡只呈現置中內文。草稿保留在待審內容。生成圖片加上概念插畫註記，圖卡失敗會保留文案並顯示補圖原因。

## 過期、封存與展示

- 選稿期限預設 30 天，優先從來源發佈日計算。來源缺少日期時以擷取日計算，畫面標示日期依據。AI 確認的活動截止日較早時，採較早期限。
- 新自動草稿帶入上述期限。既有或手動草稿的期限可在編輯器核對及調整，長青備稿由承辦人確認有效期限。
- 擷取後 90 天自動封存，執行中的素材先等待工作結束。封存保留原文、圖庫和關聯紀錄，可手動還原。還原後仍按原有日期計算時效。
- 系統不自動永久刪除來源資料。承辦人可刪除待審草稿，已有發佈紀錄的貼文保留核對。
- 素材、待審稿、圖庫與發佈紀錄提供分類、月份分組、時間範圍、排序及每頁 12 筆展示。素材另有封存與還原操作，AI 語意選稿時可自動分類，也可人工分類或在來源設定預設分類。

## API 平台選項

建立／編輯貼文的發佈平台，以及手動發佈的目標，依必要 API 欄位是否填齊顯示。缺少 API 仍可製作四版文案及儲存草稿。核准、手動發佈與排程都會在後端檢查平台設定。憑證填齊後，應再按連線檢查及驗收發文權限。
