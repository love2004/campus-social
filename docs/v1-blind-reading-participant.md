# 社群貼文匿名試讀問卷

請閱讀同一情境的兩篇社群貼文，再依照下列題目回答。研究人員會在每篇貼文上標示代碼。請用自己的話回答，從貼文中找不到資訊時可寫「文中未說明」。請先完成第一篇的題目，再閱讀第二篇。

受試者代碼 ______________　　情境代碼 ______________

## S01 學校活動通知

假設你是在校學生或家長，在學校社群頁看到這篇貼文。

1. 這場活動會做什麼？請用一句話說明。
2. 如果你想參加，活動是哪一天、幾點、在哪裡？你要怎麼報名？
3. 你看完後還需要問學校哪一件事，才有辦法決定是否參加？

## A01 協會知識分享

假設你是一般社群讀者，平常偶爾會閱讀協會的生活知識貼文。

1. 就算你沒有參加講座，看完這篇仍能帶走什麼觀念？請用自己的話說明。
2. 假設兩件物品的標示瓦數相同，但使用時間不同。依這篇的說法，你會用什麼資訊估算它們的耗電量？
3. 文中若提到新聞、生活情境或網路梗，它有沒有幫你理解重點？請指出是哪一段。若你沒看懂或文中沒有，可直接寫出。

## C01 公司產品通知

假設你是該公司產品的門市使用者，正在安排一場可能遇到網路中斷的活動。

1. 新功能可以在斷網時做什麼？恢復連線後會怎麼處理？
2. 如果你想在活動前試用，要先做哪一步準備？請再說出一項使用限制。
3. 依貼文資訊，你會採取什麼下一步？哪一段讓你這樣判斷？

## 每篇貼文評分

看完一篇填一次。1 代表非常不同意，3 代表普通，5 代表非常同意。「時事、情境或梗」一題也可填「不適用」。
