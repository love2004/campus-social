## 操作

1. 在「單位設定 → AI 與用量」啟用 AI 概念生圖。
2. 生圖服務選「Codex 訂閱生圖（不需 API 金鑰）」並儲存。舊設定沒有 `imageProvider` 時會補入此預設值。
3. 到「圖片工作室」開啟 AI 生圖，或從貼文開啟圖卡編輯器。
4. 選擇貼文主題或填入配圖描述，按「依這個主題生成配圖」。過程可能需要數分鐘，避免重複提交。
5. 完成後底圖會匯入圖庫並選入編輯器，可加上標題與摘要，再儲存圖卡。

自動產稿也使用同一個生圖服務選項；若要自動製卡，在「自動化規則」另選 AI 生成底圖再自動加字。人工模式不會因啟用生圖而自行產生圖片。

## 實作

- `selfhost/core.mjs`：新增 `imageProvider`，可選 `codex` 或 `openai`，預設 `codex`。
- `selfhost/codex-image.mjs`：使用主機 ChatGPT 登入啟動固定參數的 Codex CLI，啟用內建 `image_generation`，停用 shell、apps 與 plugins。
- 以 JSON Schema 取得生成檔案絕對路徑；只允許本次工作目錄或 Codex `generated_images` 範圍，檢查實際路徑、檔案大小及新生成時間，避免匯入其他檔案。
- 生圖請求最長 10 分鐘，以 SQLite 租約限制同時一個 Codex 生圖工作。額度、授權或工具錯誤回報給使用者，不自動改用 API。
- `selfhost/media.mjs`：按服務分流，將 Codex 圖片交給原有 Sharp 匯入及圖卡流程，保存 `provider` 與對應貼文。
- Codex 分支不讀取 API 金鑰、不呼叫 Images API，也不計入美元 API 預算保留；訂閱實際用量由提供者管理。
- API 分支保留現有金鑰、模型與預算保留設定，須使用者明確選用。

## 必要條件與驗收範圍

主機須安裝支援內建生圖的 Codex CLI，並以有生圖資格的 ChatGPT 帳號登入。目前 Windows 本機 `codex exec` 生圖與網頁操作已實測成功；目標 Linux 主機仍須以該主機帳號驗收。

官方文件說明內建生圖計入一般 Codex 額度，平均消耗可能比類似純文字回合快約 3～5 倍，仍依品質與尺寸而異。文件亦提供以 API 進行程式化生圖的路徑，本專案新增的 CLI 包裝層應在實際主機驗收後再用於常態排程。
