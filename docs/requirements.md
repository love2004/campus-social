# 已確認的第一版規格

確認日期：2026-11-04（Asia/Taipei）。使用者已逐題完成需求訪談並確認開發。

- 每個單位的社群承辦人可各自部署一套，管理各自的帳號與資料。
- Linux 常駐主機；承辦人關機後，來源整理、產稿與已核准內容的發佈繼續運作。
- 管理網站可在校內外登入，支援手機。
- Facebook 粉專、Instagram、Threads、LINE 官方帳號好友群發。
- 手動提供文字與圖片，或指定官方／外部公開文章網站；依主題、包含與排除關鍵字、篇數上限篩選。
- 同一素材產生各平台版本，集中預覽、修改、審核，可選擇發佈平台。
- 支援文字、單張與多張圖片、挑選和排序。品牌色、Logo、標題與日期套版為基本能力；AI 概念生圖為選用功能。
- 承辦人只審內容；核准後加入佇列。四平台共用每週發文日與時段。
- 一般核准內容優先；無合適內容時使用已核准且有效的備稿；皆無則略過並通知。
- AI 優先使用既有訂閱；付費功能由管理者主動啟用，有本機用量上限與提醒。
- 訂閱額度不足／授權失效時暫停產稿並寄信；已核准內容繼續發佈，不自動切換 API 計費。
- 電子郵件通知：每日待審摘要，重要異常即時排入寄送。
- 每平台正文預設 200～300 字，直接說明背景、彙整可核對的重點與具體總結；標題與導流連結不能取代內容。字數可在單位設定調整。
- 圖片以主題圖文卡片呈現：配圖與標題、摘要、單位註記分層。可用 AI 概念配圖或現有照片，修改文字、位置、字級、色彩、對齊、尺寸與背景裁切。儲存原圖與版面設定，匯出新圖片並重新審核。

## 執行層的具體規則

台北時區；每篇內容預設只發一次。修改事實相關內容、圖片、平台、來源、期限都撤回核准。已進入發佈程序的貼文保留原始版本，可複製成新草稿。每平台獨立保存結果；未知結果不能自動重送。主機中斷後僅在允許的延遲範圍補送，過舊的排程記錄為錯過。

訂閱整合區分「單位擁有的可信私有 Codex 定期工作」與「對外提供任意 AI 服務」。本版本僅將有界的產稿工作送交單一序列的主機 CLI，不提供 CLI／app-server／任意指令給網站訪客。登入檢查不代表已完成產稿驗收；第一次成功完成結構化產稿才顯示產稿驗證時間。正式部署的帳號資格與適用條件仍由部署者確認。
